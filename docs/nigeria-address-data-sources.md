# Nigeria Checkout Address Data

The structured checkout selector uses state and LGA data based on the Nigeria GeoJSON dataset by Temi Kolawole (`temikeezy/nigeria-geojson-data`), which supplies `states.json` for all 36 states and the FCT plus `lgas.json` mapping each state to its local government areas. The repository is MIT-licensed.

The structure and countrywide administrative coverage were cross-checked against the Humanitarian Data Exchange Nigeria Subnational Administrative Boundaries dataset, whose sources include Nigeria's Office for the Surveyor General of the Federation and which lists Nigeria administrative levels through LGAs.

Source URLs:

- https://github.com/temikeezy/nigeria-geojson-data
- https://data.humdata.org/dataset/cod-ab-nga
